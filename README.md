# Sigil Creator

Personal magical sigils from user intentions using methods from classical grimoires and modern chaos magic — Austin Osman Spare letter reduction, Agrippa planetary kameas, Golden Dawn Rose Cross, and grimoire-style seals.

Supports Sigil Profiles (visual styles) such as Antiquarian Calligraphic.

This is a Grok skill. See `SKILL.md` for the full specification.

## Structure

- `SKILL.md` — Skill definition and workflow
- `profiles/` — Visual style YAML definitions
- `references/` — Methods and kamea squares
- `scripts/` — Helper scripts for letter reduction and number conversion
